# Kit de diffusion pour Escape Game Studio

Ce fichier sert a publier des descriptions coherentes d'Escape Game Studio sur GitHub, reseaux sociaux, annuaires, forums enseignants/formateurs et plateformes de lancement.

## URL principale

https://escape-game-studio.netlify.app/

## Description courte

Escape Game Studio est une application web no-code pour creer, tester, partager et publier des escape games interactifs en ligne.

## Description moyenne

Escape Game Studio aide les enseignants, formateurs, createurs, animateurs et entreprises a transformer une idee de scenario en escape game jouable dans le navigateur. Le builder permet de creer des scenes, ajouter des zones cliquables, gerer des objets, ecrire des enigmes, definir des regles conditionnelles, tester le parcours joueur, corriger les blocages puis partager ou publier le jeu.

## Description pour annuaire

Escape Game Studio est un logiciel no-code francais pour creer des escape games interactifs en ligne. L'outil rassemble scenarisation, scenes, medias, objets, inventaire, enigmes, logique conditionnelle, preview joueur, bilan de coherence et publication. Il s'adresse aux enseignants, formateurs, createurs de jeux, entreprises et animateurs qui veulent prototyper une experience jouable sans developper un moteur de jeu.
